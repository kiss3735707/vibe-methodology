# 示例：验收清单与成功标准（对照）

> 这些是教学示例，**不要原样复制进项目模板**。语言和命令按你的栈替换。

## 成功标准：坏 vs 好

| 坏（不可证伪） | 好（输入 + 操作 + 可观察输出） |
|----------------|------------------------------|
| 投篮手感更好 | 按住 J ≥ 400ms 后松手，球走抛物线；进筐显示 +1 或 +2 |
| 体验流畅 | 60fps 下 `update(dt)` 单帧 < 8ms（用现有基准脚本） |
| 代码更清晰 | 本里程碑不新增抽象层；`physics` 仍无 UI 依赖 |
| 验证更完善 | `{test_cmd}` 新增非法输入用例且全量 x/x 通过 |

## 用户验收清单示例（界面 / 手感类）

仅当自动化断言覆盖不了时使用。Agent 列出清单，**等用户打勾**。

```
□ 按住 J 蓄力松手投篮，球沿抛物线进筐 → 显示 +1/+2
□ 贴筐出手 → 走上篮路径，命中率合理
□ 传球穿筐 → 不计分（防误判回归）
```
